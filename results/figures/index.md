## F4_model_comparison

## F5_concordance

Files: `F5_concordance.pdf`, `F5_concordance.png`

Draft caption: Ordering of attrition between experimental and control arms within the same trial. Concordance is the share of experimental-control arm pairs whose attrition order is predicted correctly (0.5 = chance; dashed line). Subsets: all test trials; reliable pairs (both arms started ≥100); covered trials (all experimental arms have prior evidence for the same drug); both. The trial-level model is omitted because it predicts no within-trial difference by construction. Points: estimates with 95% trial-grouped bootstrap intervals.

## F6_conformal

Files: `F6_conformal.pdf`, `F6_conformal.png`

Draft caption: Split-conformal 90% prediction intervals for the primary arm attrition rate (FINAL model, calibrated on validation arms). (a) Empirical test coverage with 95% bootstrap intervals; dashed line = target. (b) Mean interval width. Mondrian intervals use a separate residual quantile per arm-size bin; normalized intervals scale residuals by the binomial standard error. Arm size is the observed number started, used as a proxy for the planned arm size.

## F7_recruitment_frontier

Files: `F7_recruitment_frontier.pdf`, `F7_recruitment_frontier.png`

Draft caption: Recruitment trade-off on test arms. Each point is a planning rule: recruitment target = required completers / (1 − assumed attrition). Fixed rule: assumed attrition 5–50%; reference class: per-arm reference-class mean plus a margin of 0–30 percentage points; FINAL: one-sided Mondrian conformal upper quantile at levels 0.50–0.95. Bands: 95% trial-grouped bootstrap intervals. Lower-left is better; dashed lines mark the 10% and 20% under-recruitment rates used for matched comparison.

## F8_shap_families

Files: `F8_shap_families.pdf`, `F8_shap_families.png`

Draft caption: Feature-family attribution for the FINAL model (TreeSHAP, test arms, log-odds scale). Bars show each family's share of the summed mean absolute SHAP value for the arm attrition rate and for five reason proportions. Family shares are sums over features and therefore grow with family size (feature counts in the legend); prior-evidence features are missing for about three quarters of test arms.
